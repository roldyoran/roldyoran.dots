# roldyoran.dots

Mi colección personal de archivos de configuración (dotfiles) para diferentes herramientas y entornos de desarrollo.

## 📁 Estructura

```
├── nvim/           # Configuración de Neovim
├── vscode/         # Configuración de Visual Studio Code
└── windows/        # Configuraciones para Windows
    ├── terminal/   # Windows Terminal
    └── oh-my-posh/ # Oh My Posh prompt
```

## 🚀 Instalación

Clona el repositorio:

```bash
git clone https://github.com/roldyoran/roldyoran.dots.git
cd roldyoran.dots
```

## 💻 Configuraciones incluidas

- **Neovim**: Configuración completa con plugins y configuraciones personalizadas
- **VS Code**: Extensiones y configuraciones del editor
- **Windows Terminal**: Temas y configuraciones
- **Oh My Posh**: Tema personalizado para el prompt

## 📝 Uso

Cada directorio contiene las configuraciones específicas para cada herramienta. Revisa los archivos individuales para instrucciones de instalación específicas.
